# Amazon Selenium Automation Framework

Web automation framework built using Selenium WebDriver, Java, TestNG, and Page Object Model (POM).

## 🚀 Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)
* IntelliJ IDEA

---

## 📌 Project Overview

This project automates key workflows on Amazon web application using Selenium automation framework.

Automated scenarios include:

* Amazon search functionality
* Product validation
* Navigation workflows
* Assertions and validations
